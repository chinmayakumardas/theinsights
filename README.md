# 🚀 Insights

**Insights** is a modern, SEO-first technology blog built with **Next.js**, **Sanity CMS**, and **Tailwind CSS**. It focuses on publishing high-quality content about SEO, Artificial Intelligence, Web Development, Programming, and Digital Marketing while delivering excellent performance and user experience.

**Live Website:** https://insights.chinmayakumardas.com

---

# ✨ Features

* 📝 Modern blog platform
* ⚡ Next.js App Router
* 🎨 Responsive UI with Tailwind CSS
* 📰 Dynamic articles powered by Sanity CMS
* 🗂️ Category-based article organization
* 🔍 SEO-optimized metadata
* 🤖 robots.txt
* 🗺️ Dynamic sitemap.xml
* 📡 RSS Feed
* 🤖 llms.txt
* 📱 Mobile-friendly navigation
* 🌙 Clean and minimal design
* 🚀 Optimized performance

# 🚀 Getting Started

## Clone the repository

```bash
git clone https://github.com/chinmayakumardas/theinsights.git
```

```bash
cd theinsights
```

## Install dependencies

```bash
npm install
```

## Configure environment variables

Create a `.env.local` file.

```env
NEXT_PUBLIC_SITE_URL=

NEXT_PUBLIC_SANITY_PROJECT_ID=
NEXT_PUBLIC_SANITY_DATASET=
NEXT_PUBLIC_SANITY_API_VERSION=

NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION=
NEXT_PUBLIC_GA_MEASUREMENT_ID=
```

## Start the development server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
